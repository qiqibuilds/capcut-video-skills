# Story tapping intro

Build a vertical intro in which a real person appears in front of a feed interface, taps a story circle, and opens the reveal clip. Match the user's reference tutorial when one is supplied; the timing and target circle are editable choices, not fixed values.

## Assets

Require three roles before building: (1) a high-resolution screenshot or recording of the opening screen with the target story circle visible, (2) a vertical video of the person rising or reaching toward that circle, and (3) the video that plays after the tap. Request additional profile or post screenshots only if the reference's opening or transition actually uses them. If the user has not supplied a role, show what to prepare, including start, mid-reach, and tap poses for the motion clip.

The reach footage should match the screen's portrait framing. A locked camera, good light, a clear hand/background boundary, and a brief hold at the tap make the cutout more stable. Check the source frames: editing cannot recover a sharp hand from severe motion blur.

## Build in CapCut

Use the connected CapCut editing tools for drafts they can edit. For an existing desktop-only project, use the desktop editor when the connected tools cannot address that project. Do not start a new rough cut when the user is asking to fix an existing draft.

1. Choose the opening screenshot and tap target. Align the reach footage so the hand lands inside the intended story circle. Keep the opening screen readable at the final vertical size.
2. Stack the opening sequence from bottom to top:
   - original reach footage as the base view;
   - a screen graphic above it, with a transparent opening where the real-world footage should show through;
   - a synchronized duplicate of the reach footage above the graphic, with the background removed so the person and hand overlap the interface.
   This order matters: changing the bottom clip cannot repair a disappearing foreground hand.
3. Align both reach copies frame-for-frame. Trim their ends together. Cut from the opening composition to the reveal clip on or immediately after the visible tap. Use a zoom or other transition only when it matches the reference and improves the action.
4. Refine the **top** reach copy at **Video → Remove BG**. Start with Auto removal, then inspect the hand frame by frame during the reach and tap. CapCut's **Custom removal** has a manual brush and eraser for local correction. Paint only the missing hand; inspect adjacent frames before accepting it. If the brush brings background objects over the story circles, erase the spill or undo that correction. A short clean cut or a reshoot is preferable to obvious background artifacts.
5. Check the first frame, the start and middle of the reach, every frame near the tap, and the first reveal frame at full preview size. Verify that the hand stays visible, the subject edge is clean, the tap lands in the circle, and the transition has no blank or mismatched frame. Do not call the edit clean if the hand flickers or is visibly blurred.

Leave the draft ready to watch in CapCut and tell the user where to preview it. Export only when the user asks for an export or has already authorized one. Report any remaining source-footage limitation plainly.
